# HerWay

A safety-focused dashboard for the HerWay app.

## Private recordings

The Home dashboard includes a visible audio/video recorder. Recording starts
only after the user presses **Record**, shows an on-screen recording indicator,
and stops when the recorder screen or app is left. Recordings are saved in the
app's private documents directory on the device and listed in the recorder
screen. They are not sent to contacts or uploaded, and the app does not record
in the background.
